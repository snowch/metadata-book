A scheduler prepares a compatible JSON event saying the job completed. The catalogue and investigator need that history. Does the document alone establish a working connection, or make the record retrievable? Pause and name what else the producer and receiver must agree.

A configured integration must observe the execution and emit events. Both ends need compatible transport, endpoint and authentication, with submission permission. Even a successful HTTP acknowledgement is not proof that the record is already queryable. Check errors, retries and gaps. Neither the event schema nor HTTP guarantees exactly-once delivery.

Now suppose another scheduler also has a job called build_delivery_summary and a local execution label R1205. If both send those short names, can the receiver reliably identify which execution belongs to which system? Explain what identity information is missing before continuing.

Read the event as a sourced completion claim. It names input and output datasets, but does not preserve the retained input snapshot, code version, output version or report refresh.
